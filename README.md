# E-Shifts
E-Shifts is a Java application for managing workplace shifts.
The application can be launched with either a JavaFX GUI or a CLI.

## Requirements
- JDK 23
- MySQL Server 8+
- An internet connection on first execution, so Maven can download dependencies

## Database setup
1. Open MySQL Workbench.
